# Flujos de usuario

## Flujo 1: Compra sin pago en línea

1. Usuario navega catálogo.
2. Agrega productos al carrito.
3. Revisa resumen y total.
4. Completa checkout.
5. Envía pedido.
6. Ve mensaje de confirmación + número de pedido.

## Flujo 2: Solicitud de información

1. Usuario abre formulario de contacto.
2. Completa datos y mensaje.
3. Envía formulario.
4. Recibe confirmación de recepción.

## Flujo 3: Gestión interna

1. Equipo recibe pedido.
2. Cambia estado a `confirmado`.
3. Actualiza estado según avance.
4. Cierra pedido en `entregado` o `cancelado`.
