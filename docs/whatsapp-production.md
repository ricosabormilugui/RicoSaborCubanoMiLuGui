# WhatsApp en producción

WhatsApp queda limitado a contacto manual mediante enlace público `wa.me`.

- No se usa WhatsApp Cloud API.
- No se usa webhook de WhatsApp.
- No se envían notificaciones automáticas por WhatsApp.
- Las notificaciones automáticas de pedidos, cambios de estado y contactos se envían solo por email.
