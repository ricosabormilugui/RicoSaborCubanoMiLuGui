# Assets pendientes de MIXSABOR

Colocar aquí, sin cambiar sus proporciones ni aplicar filtros CSS:

- `mixsabor-logo-light.png`: variante preparada para fondos claros.
- `mixsabor-logo-dark.png`: variante preparada para fondos oscuros.

Tras incorporar y revisar ambos archivos, cambiar `logos.available` a `true` en
`shared/brand.config.json`. Mientras falten, la interfaz muestra el wordmark de
texto `MIXSABOR` para evitar imágenes rotas.

También siguen pendientes un favicon legible, `apple-touch-icon` y una imagen
social de marca. No se generan automáticamente a partir del logo complejo.
